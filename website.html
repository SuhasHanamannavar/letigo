FAQ

Questions, answered.

Litigo is a cross-platform tool that lets you define rules once and enforce them across AI chatbot conversations. It runs alongside ChatGPT, Claude, Gemini, and other supported chatbots, analyzing responses in real time and showing compliance status and any violations.
Litigo currently supports ChatGPT, Claude, Gemini, Perplexity, Microsoft Copilot, and Grok. The adapter architecture is designed to allow additional chatbot integrations to be added without rewriting the core engine.
Rules are user-defined constraints that AI responses must satisfy. Examples include word limits, formatting requirements, citation policies, and tone guidelines. Each rule can be enabled or disabled, prioritized, and applied to specific chatbots.
Litigo analyzes chatbot responses locally on your device to evaluate them against your rules. The analysis happens on-device through WebAssembly. Conversation content is never transmitted to Litigo servers unless you explicitly enable optional features that require it.
Rule matching, compliance analysis, and semantic evaluation are all processed locally. Cloud services are used only for authentication, subscription management, and optional end-to-end encrypted cross-device synchronization — never for conversation content.
Litigo is available as a Chrome extension, Windows desktop app, macOS desktop app, Android app, and iPhone app. Each platform uses native system mechanisms appropriate to that OS — system tray on Windows, menu bar on macOS, floating overlay on Android, and keyboard extension on iOS.
The Chrome extension uses Manifest V3 and a chatbot adapter architecture. Each supported chatbot has a dedicated adapter that handles detection, response observation, UI injection, and rule evaluation — keeping site-specific logic isolated and maintainable.
